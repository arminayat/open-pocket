# Implementation patterns

Use small modules and typed boundaries. Keep protocol parsing/test helpers independent of React Native. Subscribe before device writes, bound every native BLE write with a deadline (a stalled write is fatal, even for optional info requests), retain reply history for early responses, and serialize control writes.

Only promote a temporary file when exact bytes and the transport completion signal are verified. Cancellation removes partial files; completed publication is the terminal boundary. Metadata writes to a fresh snapshot via a temporary file and same-folder rename before pruning prior snapshots, preserving the previous library on write failure. Recorder commits and iCloud adoption share one index publication queue; cloud imports never run startup partial-file cleanup and retain verified orphan audio if the index write fails. The recording library can recover an older readable snapshot; transcription and notes require the latest committed snapshot so stale jobs or text cannot silently replace current state. Wi-Fi uses one hotspot session per recording. Failed transfers disconnect before another attempt.

Use diagnostic allowlists and register secrets before they can reach errors. Never print raw auth/recorder responses. Update these notes when behavior changes. UI uses HeroUI primitives and Uniwind theme tokens. Accessibility font scaling remains enabled.

Transcription has a separate serialized owner; never reuse ChatGPT OAuth tokens as API keys. Store intent before sending audio, persist accepted AssemblyAI IDs before polling, and resume known jobs using GET only. Never automatically retry a billable POST. The submission receipt has a bounded grace period on cancellation so an already accepted job ID can still be saved. Retain receipts/results in memory if disk writes fail, retry local publication before continuing, and never replace a completed result with a save error. Keys stay in Keychain/closure state; errors use fixed messages without provider bodies. Validate provider URLs, the exact local file and size, and bounded responses at their trust boundaries. Completed transcripts use relative file identity, not iOS container paths. Pure controller/adapter tests inject storage and transport; no real accounts, audio uploads, or billing in automated checks.

Note and transcript imports publish local storage before exposing merged state. Note edits carry expected revisions; an open draft survives failed publication and concurrent sync. A draft is also bound to its local recording key so a newly selected copy requires review. iCloud merges carry the run's expected note revision/transcript state into the serialized owner, atomically rejecting changes made during that run until a later run archives them. Busy owners reject imports for retry instead of silently dropping them. Note ordering uses timestamp then UUID; completed transcripts use timestamp then canonical provider/model/text payload. Empty notes are deliberate revisions, not missing data.

iCloud consent is tied to the current Apple account, defaults off, and must persist before writes begin. Off/background/account changes revoke the native session and queued publication authority immediately. Check consent around asynchronous boundaries; native code rechecks before final publication. Validate exact archive paths/schema, reject symlinks, and verify imported audio size/hash. Publish local text revisions before adopting cloud text, retain immutable cloud versions, and block replacement when a local version has not been safely archived. Missing files never authorize deletion. Keys, OAuth state, jobs, errors, and diagnostics do not belong in cloud artifacts. Distinguish local publication, Apple's upload status, pending materialization, conflicts, and receipt on another device.

ChatGPT account logic is independent of Pocket credentials. Persist issued registration IDs before code exchange so failed attempts can reuse them; preserve the active account until signature, issuer, audience, nonce, expiry, and returning subject are verified. Only token-response scopes grant plan permission. Keep tokens out of React state, diagnostics, and browser storage. Serialize refresh and Keychain replacement; transient errors retain credentials, terminal refresh errors clear tokens but retain registration. Retry failed persistence before rotating again, retaining the latest rotated token only in memory until saved. Sign-out blocks renewal immediately and remains retryable if local credential removal fails. Synthetic tests inject storage/auth/HTTP dependencies; never perform live login or model calls in automated checks.

Automatic work uses `run(stage, work, quiet = true)`: same lock and busy state as user actions, but errors only go to diagnostics. The next automatic download is chosen by the pure `nextAutoDownload` helper. Setup completion is derived from the verified saved connection in PocketContext, not separate state; the selected recorder is local to the stepper and resets when the nearby list is cleared. Saved reconnect uses the verified saved key, even after importing a different candidate. Verification labels compare the active key with the saved key. Disconnect and new connection attempts clear remote listings. Playback resolves the latest local copy and explicitly enables silent-mode media playback.
