# App overview

OpenPocket is an iPhone-first experiment for connecting to an already-activated Pocket recorder. Expo/HeroUI UI controls direct Bluetooth and Wi-Fi downloads, local playback, sharing, and redacted diagnostics.

Implemented Pocket account paths: OAuth with PKCE and per-sign-in dynamic registration of a loopback redirect, personal API key lookup via MCP, and an existing device key. Account-derived keys are candidates until the recorder acknowledges them. The current candidate key (with account label) is kept in Keychain so sign-in survives restarts; verified connection details replace it once the recorder accepts. Pocket cloud tokens are never stored.

Optional ChatGPT connection is separate from recorder access. Setup and Settings support the documented open-source/local-app OAuth flow, saved account registrations, reconnect, plan-permission status, sign-out, and a ChatGPT usage link. ChatGPT credentials live in Keychain. This prepares account access for future ChatGPT features; the connection itself performs no model requests or uploads and cannot provide audio transcription. Local checks do not establish live ChatGPT/iPhone OAuth acceptance.

Downloaded recordings can be transcribed with the user's separately billed OpenAI, Deepgram, AssemblyAI, ElevenLabs, or Groq API key. Keys are saved in device-only Keychain; selecting Transcribe explicitly confirms an audio upload to the named provider. An opt-in "Transcribe automatically" switch (confirmed once per provider) uploads saved recordings without a transcript one at a time while the app is open. Transcripts are saved locally and can be previewed, opened in full and copied. Each saved recording also has user-written, editable notes. AI titles and summaries (read-only, never typed) are written from finished transcripts by the user's chosen AI provider: ChatGPT plan usage through Sign in with ChatGPT, or the user's own OpenAI, Anthropic Claude, or OpenRouter key; manually after a confirmation, or by an opt-in automatic switch. Only transcript text is sent. No background (app-closed) transcription, automatic retries, speaker labels, arbitrary endpoints, or remote artifact deletion is implemented. See `docs/research/transcription-providers.md` for the source-backed shortlist and limitations; it is not a market-share or accuracy ranking.

Optional iCloud Drive sync, off by default, copies downloaded audio, completed saved transcripts, AI titles/summaries, and saved notes into the user's OpenPocket folder, with one folder per recording/audio checksum. Other Apple devices can access the files through Files/Finder; supported devices running OpenPocket can import them into the app with sync enabled under the same Apple account. Published text versions remain in the cloud folder. Sync never includes credentials, API keys, unfinished transcription jobs, or diagnostics. Turning it off retains local and cloud files; missing or deleted cloud files do not delete local copies. Apple manages transfer timing, and native compilation or a completed local check does not prove another device received the files.

OpenPocket for Mac (`mac/`, native SwiftUI, built with Swift Package Manager and the Command Line Tools) is a separate app in the same repo. Dictate (side switch in normal mode): a side-button press switches the default input to the Pocket Mic virtual device (`driver/`), presses the user's hotkey dictation app (OpenWhispr, Wispr Flow, …), and plays the Pocket's live MP3 into Pocket Mic. A second press presses the hotkey again and restores the input. Gestures (side switch in call mode): contact-mic taps (1/2/3), swipes and tap location (top/bottom/left/right) with confidence, mapped to user actions, plus a guided calibration. The Mac app's Recordings (iCloud library) is a placeholder until it is signed by team G6WL4CPNV3. `cli/` is the earlier Python `pocket` CLI (record, listen, dictate). Verified live on 2026-11-19 with firmware 1.8: Mac dictation through OpenWhispr, gestures, and calibration. Those were ad-hoc builds. Mac builds ship two ways (`docs/mac-release.md`): a sandboxed TestFlight variant (`mac/testflight.sh`, iPhone bundle ID, same App Store Connect app; Pocket Mic is dragged in by hand, no shell-command gestures, Shortcuts via URL) and a Developer ID–signed, notarized zip with every feature (`mac/release.sh`, not published anywhere yet).

There is no app backend, analytics, subscription, firmware modification, factory activation, or recording deletion. Verified on a physical iPhone (2026-10-22, firmware 1.8): OAuth sign-in, recorder acceptance of the account-derived key, device info, and recording listing. Bluetooth/Wi-Fi download, real-provider transcription, and signed two-device iCloud propagation remain separate from local checks.
