# Design system

HeroUI Native supplies cards, buttons, form fields, chips, and progress spinners. Uniwind supplies light/dark tokenized backgrounds, surfaces, text, separators, and states. Main navigation is Expo Router native tabs: Device, Recordings, Diagnostics.

Use safe-area-aware screens, readable Inter text, system font scaling, accessible control labels, and explicit errors. Explain connection prerequisites, cloud sign-in permission, temporary hotspot joining, and foreground download requirements in ordinary language. Keep raw protocol details in diagnostics rather than everyday flows.
